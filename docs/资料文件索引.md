# 资料文件索引

本仓库只收录可复用的 Skill、表格模板和操作说明。按自动化节点对照如下。

| 模块 | 关键文件 | 主要用途 | 自动化节点 |
| --- | --- | --- | --- |
| 实操手册 | `GEO自动化Skill_实操手册.md` | 按命令逐步跑通客户诊断、挖词、写稿、合规检查和监测计划 | 全流程入门 |
| 自动化说明 | `docs/GEO实操手册自动化说明.md` | 流程、表格结构和 Skill 用法说明 | 全流程参考 |
| skills | `doubao-geo-publisher`、`geo-keyword-miner`、`geo-article-writer`、`geo-platform-adapter`、`geo-doubao-research` | 可复用的 AI 工作流和脚本 | Skill 层 |
| 表格模板 | `templates/GEO自动化流程表格模板.xlsx` | 公司家底、客户档案、关键词库、文章任务、监测追踪等表 | N1-N6 |
| 档案与报告模板 | `templates/client_profile.sample.json`、`article-brief.template.md`、`effect-log.template.md`、`competitor-source-log.template.md`、`comparison-feedback.template.md` | 客户档案样例，以及 Brief、监测、竞品信源、对比反馈模板 | N1 / N4 / 监测复盘 |

## 可直接进入表格的字段

| 来源 | 字段 | 建议写入 |
| --- | --- | --- |
| 公司家底 | 公司信息、核心服务、目标客户、资质荣誉、真实案例、核心卖点 | `公司家底六格表` |
| E-E-A-T 模板 | 专业度、经验性、权威性、可信度 | `表一_客户档案` |
| 关键词资料 | 问答词、目标达成词、商业动作词、公式类型 | `表二_关键词库` |
| 文章资料 | 标题模板、文章类型、平台规则、引用来源 | `表三_文章任务` |
| 媒体引用资料 | 来源名、发布时间、核心数据点 | `表三_文章任务` 的引用来源字段 |
| 发布后回查 | 查询词、AI 软件、是否出现目标主体、引用来源、截图 | `表四_监测追踪` |

## 后续可继续自动化
